# Changelog

All notable changes to Careminate are documented in this file. The format follows Keep a Changelog and releases follow Semantic Versioning.

## [Unreleased]

### Added

- Separate application and framework Composer packages.
- PHP 8.4 engineering quality gates and cross-platform CI.
- Framework exception hierarchy.
- Cross-platform lexical path support.
- Semantic version parsing, comparison, and runtime version access.
- Unit, integration, architecture, and mutation-test infrastructure.
- Engineering foundation guide and architecture decision records.
- Public container, builder, contextual-binding, factory, and lifetime contracts.
- PSR-11 container implementation with transient, singleton, and scoped services.
- Constructor autowiring, primitive values, parameter overrides, attributes, aliases, and tags.
- Typed closures, factory objects, and cacheable factory classes.
- PHP 8.4 native lazy service proxies and circular-dependency diagnostics.
- Integrity-checked compiled container metadata with guarded cross-platform replacement.
- Complete dependency-container tests, documentation, and architecture decision record.
- Immutable application environment, path, option, and lifecycle-state models.
- Application kernel with ordered registration, boot, rollback, and idempotent termination.
- Isolated request and console runtime contracts backed by scoped container execution.
- Runtime and process termination diagnostics that preserve multiple cleanup failures.
- Disabled, preferred, and required production container-cache startup modes.
- Complete application-kernel tests, documentation, and architecture decision record.
